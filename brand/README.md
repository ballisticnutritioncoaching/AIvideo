# Ballistic Performance brand kit

Source: Brand Manual 4.0 (October 2026), Section 08 Visual Identity.

- `tokens.css`: colors and font stacks for the app.
- `fonts/`: Tomorrow Regular/Light, Work Sans Regular (both SIL Open Font License), Sharp Grotesk Medium (commercial, see note).
- `marks/`: the BP shorthand mark as PNG (supplied) and SVG (traced from the PNG) in all five brand colors.

## Rules the app follows
- Blue or red logo on light backgrounds, white on dark/photos. Clearspace = height of the "B" on every side.
- About 60% white, 30% blue, 10% red or less. Red is one accent per screen.
- Tomorrow uppercase for short labels, Sharp Grotesk (fallback Work Sans SemiBold) for headings, Work Sans for body.
- Copy follows the voice rules: no em dashes, no square brackets, no metabolism or guarantee claims.

## Open items
- Sharp Grotesk is a commercial typeface. Embedding it on a public website needs a web license from the foundry. Until that's confirmed, the app can fall back to Work Sans SemiBold, which the manual allows.
- Full BALLISTIC PERFORMANCE wordmark files still needed (SVG preferred).
- Culture kit badges still needed.
